How to Export "Undiluted" (High-Res) Slides

"Undiluted" presentation saving ensures zero image compression, pixelation, or broken custom fonts when delivering your pitch to investors.

Option A: Native High-Res Vector PDF (Recommended) Click "Export High-Res PDF" on the top menu bar. In the Chrome/Edge print window:
  • Destination: Save as PDF
  • Layout: Landscape
  • Margins: None
  • Check: Background Graphics
Option B: In Microsoft PowerPoint (.pptx) To prevent PowerPoint from compressing graphics automatically:
  1. Go to File > Options > Advanced
  2. Scroll to Image Size and Quality
  3. Check "Do not compress images in file"
  4. Set default resolution to "High fidelity" (300 ppi)
  5. Save as .pptx
